# Monica Rust for the Mac App Store

Monica Rust is a local relationship journal. Use **联系人** to search your contacts. Choose **新建** to add someone, then open their record to add notes, interactions, tags, or important dates.

## First launch

Open the app and wait for the startup status to show **运行中**. Choose **创建首次使用账号** to create your local account, choose **打开 Monica**, and sign in within the app. The interface uses Simplified Chinese.

## Import contacts

In **联系人**, choose **导入 CSV**. Select a UTF-8 file with up to 500 contacts and a maximum size of 64 KB. The header needs a `display_name` column. Add a `summary` column for optional notes. Review the preview and choose **确认导入**. Repeated rows with the same name and summary are skipped on subsequent imports into the same workspace.
