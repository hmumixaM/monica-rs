# 已有结构化资料与资料建议

LinkedIn 工作和教育经历已作为结构化资料保存。提示词把这些记录视为已知背景，
不因通用字段为空而建议复制、翻译或压平已有经历。保留当前与历史时间段，
不根据 LinkedIn 标题、简介或所在地推断新的工作变化或家乡；已有人工值继续保留。
没有新线索时，返回空建议列表是正常结果。

人物快照携带精简的结构化名称、职位、修订、来源和观察时间。完整来源记录仍在原位置。
结果验证及待处理列表使用同一去重规则：相同结构化值不再提示；纯 LinkedIn 资料
证据不要求把同类已记录的结构化信息填入通用字段。历史导入建议保留英文原文时，
也会识别已有结构化名称，减少翻译后的重复提醒。新动态、聊天或笔记明确提供的新值，
仍可进入正常建议验证与人工确认流程。

已有结果只在读取时过滤，不删除建议、决策或来源，不触发重新分析。
模型、凭据、执行开关、聊天及笔记许可保持原配置。本轮不运行真实模型。
