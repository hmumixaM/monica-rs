# Monica Rust support

Monica Rust is a personal contact journal. Create a contact, keep notes, and log your interactions in a timeline.

## Get started

- Choose **Add Contact** to create a contact. Select a contact in the sidebar to edit its details and log an interaction.
- Choose **File Actions → Import File** to select a local UTF-8 CSV file, vCard file, or Monica Rust JSON backup. Review the preview and choose **Import**.
- Choose **File Actions → Export Backup** to save a copy of your workspace. A backup includes contact details, notes, and interaction history.

For a CSV file, use one contact per row and include a header. The simplest supported header is `Name,Company,Email,Phone,Notes`. A file can include fewer columns as long as it has a name column. The app also recognizes common first-name and last-name header variants. Import keeps existing records when a match is found.
