# Monica Rust support

Monica Rust is a personal relationship manager for organizing people, notes, conversations, and source records.

## Get help

- Report a problem or ask a question in the [Monica Rust issue tracker](https://github.com/hmumixaM/monica-rs/issues).
- Email [Monica Rust support](mailto:max@12450.top) for help with installation, saving data, or an issue you would prefer to discuss privately.

Include your Monica Rust version, macOS version, what happened, and the steps that reproduce it. Remove personal records, credentials, and access tokens before sharing diagnostics.

## Get started

1. Open Monica Rust and wait for the local service to become ready.
2. Create a local account in the settings window. You can use an address reserved for your own local account. Monica uses it as the sign-in name on your Mac.
3. Select **Open Monica** to open the workspace. Start in **People** to add a contact or **Imports** to see the data sources available in your build.

For a failed start, use **Open logs** in the settings window. If you forget your local password, use the local account recovery panel.
