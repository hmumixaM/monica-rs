With deferred Memory recovery, those old scopes also inspect the newly ingested history, adding unrelated setup work and duplicate reconciliation. The final setup_seconds includes this work; no queue is deleted or forcibly marked complete. Both message query readiness and full Memory settlement remain timed. Generated-contact-link-backlog attempts are retained separately as diagnostics, rather than silently overwritten.
